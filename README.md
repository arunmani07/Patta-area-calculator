🌿 Patta Area Calculator

A simple, mobile-friendly land area calculator for Tamil Nadu Patta/Chitta survey measurements. Convert land extent from Hectare and Are into Acre, Cent, Ground, Square Feet, and Square Metres.

🔗 Live Website: https://arunmani07.github.io/Patta-area-calculator/

✨ Features

- English & Tamil Support — Switch between English and Tamil.
- Land Area Conversion — Convert Hectare and Are into common Tamil Nadu land measurement units.
- Multiple Survey Entries — Add multiple survey numbers and sub-divisions.
- Owner Details — Enter multiple landowners' names.
- Location Selection — Select District, Taluk, and Revenue Village.
- Live Calculation — View converted areas and total land extent.
- WhatsApp Sharing — Share a formatted land summary image with a link to the calculator.
- PDF Export — Print or save the land summary as a PDF.
- Save & History — Save calculations locally and restore previous entries.
- Copy Results — Copy formatted land details for sharing.
- Responsive Design — Designed for desktop and mobile devices.
- Privacy Information — Explains browser storage and external services.

🧮 Conversion Formulas

The calculator uses the following conversions:

- Square Metres = (Hectare × 10,000) + (Are × 100)
- Acres = Square Metres ÷ 4,046.8564224
- Cents = Square Metres ÷ 40.468564224
- Grounds = Square Metres ÷ 222.967104
- Square Feet = Square Metres × 10.7639104167

These conversions are mathematical calculations for reference purposes. Always verify land details against official records.

🚀 Getting Started

Run Locally

1. Download or clone this repository.
2. Open the project folder.
3. Open the HTML file in a modern web browser.
4. Enter Patta details and survey measurements.
5. Review the converted area and total land extent.
6. Copy, save, export, or share the results as needed.

Deploy with GitHub Pages

1. Upload the project files to your GitHub repository.
2. Open Settings → Pages.
3. Under Build and deployment, select Deploy from a branch.
4. Select the "main" branch and "/ (root)" folder.
5. Save the settings and wait for deployment.

🔒 Privacy & Data Safety

- Calculations are performed in the browser.
- Saved calculations and history use browser storage on the device.
- Clearing browser storage may remove saved calculations.
- Location dropdowns and visitor-count features may use external services and require an internet connection.
- Avoid entering unnecessary sensitive personal information.
- Use the site's data-deletion option to remove saved calculations from the current browser.
